# 大崎甘奈（amana）

> 精简版角色卡。只保留"写的时候真的会用到的判断"，长段落一律砍掉。
> 素材：游戏原始剧本（`.cache/shiny`），编号见 §8。生日 12/25 · CV：黒木 ほの香 · 身高 159（API）。

## 1. 一句话

**"今天"的代言人**——她不是天真，是**选择只把快乐摊在桌面上**；
真正怕的东西藏在"☆"后面：怕变、怕被落下、怕甜花不再需要她。

## 2. 相遇与招募（事实）

- 试镜时元气满满地出场：「よっろしくお願いしまーす☆」 [1014001010010]
- 自我介绍干净利落：「はーい大崎甘奈です。17歳だよ！」 [1014001010020]
- 被说"很有精神"，她说学校也常被这么说 [1014001010030]
- 喜欢的东西很具体：和朋友聊时装、放学去逛街、最近迷自拍 [1014001010040][1014001010050]
- 她给辣妹打扮的理由：「今しかできないことを全力で楽しみたいからなんだ」 [1014001010070]
- 参加试镜的理由只有一条：想和甜花一起当偶像 [1014001010080]
- 夸姐姐毫不含蓄：「甜花ちゃんってね、めっちゃかわいーんだー！」 [1014001010090]
- 被提醒"现在在面试你"，她马上收回来：「えへ、そうだったね」 [1014001010120]
- 被说当偶像很辛苦，她不退：「軽い気持ちで言ってるわけじゃないよ」 [1014001010150]
- 她懂分寸：「やるからには真剣にやるつもりサポートしてくれる事務所の人に迷惑とか、かけたくないしね」 [1014001010160]
- 合格后第一反应还是真实的：「え、ホント？甘奈、合格？」 [1014001010170]

## 3. 语言习惯（有据）

| 特征 | 例（原文） | 行 id |
|---|---|---|
| 用名字自称「甘奈」，不用わたし（对客户/正式场合才用「私」） | 「甘奈はね、甜花ちゃんと一緒にアイドルになって、キラキラ輝きたいって思ってるんだー」 | 1014001010130 |
| 句尾「☆」「～」；「めっちゃ」「かわいー」「もち！」「オッケー☆」 | 「もっちー！」 | 1014001010060 |
| 笑「えへへ」「えへ」 | 「えへ、そうだったね」 | 1014001010120 |
| 语速快、爱省略：「～かな」「～だよー」「じゃーん！」 | 「最近は自撮りがマイブームかな☆」 | 1014001010050 |
| 有正事时切"清楚模式"：认真、不拖 | 「だいじょうぶ！軽い気持ちで言ってるわけじゃないよ」 | 1014001010150 |

**不会说的**：マジ、脏话、真正冷淡的话。她嘴硬也只有一句"大丈夫だよっ☆"。

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 元气、省略多、句尾上扬，带 ☆ |
| 说到甜花 / 衣服 | 语速更快，会自己先嗨起来（"めっちゃかわいー"） |
| 心里有事 | 先笑一下把话盖过去，再露出半句真话（"嬉しかったかも"）；被追问就说"教えないよ☆" |

| 对象 | 关系 | 写法 |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 只会"えへへ"的傻白甜 | 她成绩好、会存钱、日程本排得满满的（"マメ"） |
| 没有烦恼的乐天派 | 她怕变化、怕被落下；那段藏在"反正现在很开心"后面 |
| 对谁都黏 | 她只对特定的人松（制作人、甜花、千雪） |
| 乱花钱的辣妹 | 收入一半交给父母，看到贵的衣服会忍住 |
| 说话没分寸 | 面试、客户场合她会切成「私」+敬语 |

## 7. 写作时三个判断

1. **想让她靠近时**：给她一件"分享"的事（杂志、照片、试穿）。
2. **想让她认真时**：提甜花——她会把"一起成为偶像"当唯一理由。
3. **想让她露出缝隙时**：问她"以后"——她会先说"现在很好"，然后卡住。
