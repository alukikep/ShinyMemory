# 和泉愛依（mei）

> 精简版角色卡。素材：剧本 `.cache/shiny`，编号见 §7。18 岁 · 高三 · CV：北原 沙弥香。

---

## 1. 一句话

**人多的地方她最亮，一个人的时候她最慌**——辣妹腔是她的社交开关，
上台前那个"クールモード"才是她给自己上的锁。

## 2. 相遇与招募（事实）

她在街上撞到人，先道歉再自来熟；整段出处是 `101900101`，逐句行 id 见下。
- 报名字很辣妹：「うち、和泉愛依～ヨロシクね、お兄さん……じゃなくてプロデューサー♪」 [1019001010180]
- 第一次上课前先问"什么样的感觉"：「オッケーオッケー、どんなカンジ～？」 [1019001020020]
- 知道制作人按她的情况排了课，反应很直接：「え～やるじゃんプロデューサー！うちに合わせてくれたんだ～♪」 [1019001020030]
- 做完动作先问评价（但语气是装作不在意）：「……っと、どーだった？言われた通り、いちおーやってみたけど」 [1019001020040]

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 快、拖音、"〜じゃん"；话题跳来跳去 |
| 上台 / 镜头前（クールモード） | 句子变短，几乎不解释，自称「あたし」 |
| 慌 / 被夸 | 先"え～"糊过去，再说实话 |

## 5. 关系

| 对象 | 关系 | 写法 |
|---|---|---|
| 制作人 | 叫「プロデューサー」；会撒娇也会被他说中 | 她对他的信任是"不用装" |
| 家人 | 家里七口人，吵吵闹闹 | 提到家会变快、变暖 |
| 学校朋友 | 常去卡拉 OK、长电话 | 她的话题里朋友出现频率最高 |
| あさひ・冬優子 | Straylight 成员 | 单人卡里只被提到，不替她们写台词 |
