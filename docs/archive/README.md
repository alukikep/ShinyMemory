# 历史归档

这里的文档保留历史决策和已完成方案，**不代表当前实现状态**。

当前进度请看 [当前路线图](../current/roadmap.md)。

## 归档分类

| 目录/文件 | 说明 |
|---|---|
| `roadmap-v0.5.md` | 2026-10-27 内容重置前的路线图 |
| `phase-c-plan.md` | 已完成的 Phase C 视觉/名册计划 |
| `post-phase-c-roadmap.md` | Phase C 之后的旧路线图 |
| `visual-migration-plan.md` | 旧视觉迁移计划 |
| `job-day-events-plan.md` | 旧工作日事件计划 |

## 使用规则

- 不要在归档文档上继续更新“当前状态”。
- 需要恢复某个旧方案时，先复制到 `docs/current/` 或 `docs/systems/`，再修改。
- 归档文档里的链接可能指向旧的目录结构。
