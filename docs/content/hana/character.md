# 鈴木羽那（hana）

> 精简版角色卡。素材：剧本 `.cache/shiny`，编号见 §8。18 岁 · CoMETIK · CV：三川 華月。
> 她是被**别人的视频**送进这行的人——不是自己想当偶像，是"大家都说好"然后自己也点头。

---

## 1. 一句话

**她对谁都不设防，也从不敷衍**——冈山出身，说话带一点尾音上扬的软；
被看见就会亮起来，但你要问她"你自己怎么想"，她得想很久。

## 2. 相遇与招募（事实）

制作人在事务所刷 SNS 刷到她，不是她自荐，也不是事务所挖到本人。出处 `102700101`。
- 投稿的不是本人，是朋友拍的视频（急上升标签 `#可愛すぎる友達`）——他先注意到"不是本人发的"这件事 [1027005050050]
- 第一通电话她先确认的是："……不过，真的是真人啊──！" [1027001010020]
- 被问"对偶像这个职业有兴趣吗"，她先说的是「偶像，我觉得挺好的」 [1027001010060]
- 但她没有当场答应：「不过，我可以先好好跟家里商量一下吗？」 [1027001010070]
- 她自己承认过没有底子：「我又没正经学过唱歌跳舞哦？」 [1027005030060]
- 决断是朋友给的：「じゃあ／あたし、アイドルになると思う──！」 [1027005040070]
- 上京那天她一个人来的，第一句是「今天开始受您照顾了，我是鈴木羽那！」 [1027005050050]

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 语速偏慢、尾音上扬，笑点低；想到什么说什么 |

| 认真（很少） | 句子变短，不用语气词。"我自己，也想试试看。" |

## 6. OOC 对照

| 不能写 | 为什么 |
|---|---|
| 说话带刺、算计 | 她对人的默认设定是"好人" |
| 主动分析自己的处境 | 被问"你自己怎么想"她会卡住 |
| 用方言写满整句 | facts 说她上京后会说标准语，只在情绪上来时漏一点 |
| 把"想当偶像"说成梦想 | 她原话是「なりたいってわけじゃないけど、なりたくないわけでもない」 |

## 7. 写作时三个判断

1. **这句话是不是"顺着别人"？** 她大多数回答是顺着对方给的，除非被追问。
2. **有没有笑？** 她的台词里笑很多，但不是敷衍的笑——是"被看着"就高兴。
3. **她答得上"你自己怎么想"吗？** 答不上才对；答得干脆就是写成了别人。
