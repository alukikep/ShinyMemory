# 大崎甜花（tenka）

> 精简版角色卡。只为了写对话时能对上她的**节奏**。
> 素材：游戏原始剧本（`.cache/shiny`），编号见 §7。生日 12/25 · CV：前川 涼子 · 身高 159（API）。

---

## 1. 一句话

**说话慢、句子碎、容易慌**——她不是没主意，是**要花三拍才敢说出口**；
真说出口的那句，往往比谁的都直。

## 2. 相遇与招募（事实）

- 被叫到名字先吓一跳：「ひゃっ！……は、はい……よろしくお願いします……」 [1015001010020]
- 她解释自己为什么慌：「甜花……あんまり、他の人と話さないから……ちょっと、びっくりしちゃっただけ……です……」 [1015001010040]
- 当偶像的理由只有一条：「なーちゃんが、一緒にアイドルになろうって……言ってくれたから……です……」 [1015001010070]
- 她管妹妹叫「なーちゃん」：「なーちゃんは……甜花の妹で……甘奈ちゃん、だから……」 [1015001010080]
- 夸妹妹：「なーちゃんは……いつも優しくて、元気で……甜花、大好き……」 [1015001010090]
- 她也怀疑自己：「甜花、アイドルなんて……できるのかなって、思うけど……」 [1015001010100]
- 但为了妹妹会往前：「なーちゃんのためにも、頑張ろうって……思います……」 [1015001010110]
- 合格后先愣住：「甜花が……アイドル……？」 [1015001010130]
- 紧张时咬字：「甜花……頑張りましゅ！」→ 马上改口「あ、頑張ります……！」 [1015001010150]

## 3. 语言习惯（有据）

| 特征 | 例（原文） | 行 id |

**不会说的**：长句、连贯的演讲、主动抢话。她一句话里最多两个分句。

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 慢、断、尾音轻；先「えっと」「う、うん」再说话 |
| 说到妹妹 | 语速稍快，句尾会带笑（"大好き"、"すごくて、キラキラしてて"） |
| 认真道谢 | 句子更短更硬，一句一个停顿：「甜花を、アイドルにしてくれて……ありがとう……」 |

## 5. 关系

| 对象 | 关系 | 写法 |
|---|---|---|
| 制作人 | 叫「プロデューサーさん」；会主动泡咖啡 | 她的道谢都是憋了很久才说的 |
| 大崎甘奈（なーちゃん） | 双胞胎妹妹，一直照顾她 | 她眼里甘奈"すごくて、キラキラしてて"；自己"なんもできなくて" |
| 桑山千雪 | 三人组里的年长者 | 「千雪さん」；靠甘奈才慢慢能说上话 |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 语速正常、句子完整 | 一句一停，常说"えと""う、うん" |
| 只会卖萌、没想法 | 她观察得很准（知道谁在帮她、谁在勉强） |
| 怕生到不说话 | 熟了会主动（泡咖啡、确认台本、管日程） |
| 懒惰 | 她只是爱睡、爱在家；该做的事会记进日程，不再犯同样的错 |
