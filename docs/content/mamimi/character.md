# 田中摩美々（mamimi）

> 精简版角色卡。只保留"写的时候真的会用到的判断"，长段落一律砍掉。
> 素材：游戏原始剧本（`.cache/shiny`），编号见文末。

## 1. 一句话

**她把真话藏在玩笑里**——先说一句让人接不住的话，再看你怎么反应；
真想说的事，一定用「〜ですよー」拖过去。

## 2. 相遇与招募（事实）

- 早上见面时她说还很困，「ふわぁ～。おはよーございまぁす」 [1005001020010]
- 对工作邀约的反应是拖长的「……へぇー、そうなんですかぁ」，不是兴奋 [1005001020020]
- 被安排拍摄时用「ほどほどにー、やってみまぁす」；嘴上不当回事，人还是去了 [2005005010140]

> 招募链的写法：**别让她说"我想当偶像"**。她是被"有点意思"吸引的。
>
> ⚠ **未验证**：她是否不登校、是否常在夜里出没——这三段剧本里都没有依据，
> 卡里不写；等读到相关剧本再补。

## 3. 语言习惯（有据）

| 特征 | 例子（原文） | 行 id | 说明 |
|---|---|---|---|
| 句尾拖长音 | 「ふわぁ～。おはよーございまぁす」 | 1005001020010 | 几乎每句都拖 |
| 自称「まみみ」 | 「まみみは悪い子なんで──」 | 2005005010070 | 卖乖/自嘲时用 |
| 反问式调侃 | 「もしかしてー……私のストーカーですかぁ？」 | 2005005110040 | 先给对方扣一顶帽子 |
| 半真半假 | 「ほどほどにー、やってみまぁす」 | 2005005010140 | 承诺时故意说得不当回事 |
| 用「ケド」转折 | 「理解が追いつかないんですケド」 | 2005005010100 | 带点挑衅的转折 |

**不会说的**：直白的感谢、正经的宣言、"我会努力的"。

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 拖长音 + 无所谓：「はぁい、ほどほどにー」 |
| 被戳中/心虚 | 语速变快、开始反问：「……え？　なんですかぁ？」 |
| 认真（极少数） | 拖长音**消失**，句子变短——这是信号，不是常态 |

## 5. 关系

| 对象 | 关系 | 写法 |
|---|---|---|
| 制作人 | 想试探、想看反应，嘴上不承认 | 调侃多于配合，但**会来** |
| 粉丝 | 会用"营业语气"糊弄 | 「ありがとー、そこそこに頑張りまぁす」 [2005005110010] |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 「我会加油的！」 | 「ほどほどにー、やってみまぁす」 |
| 直接说"谢谢你" | 「ふふー、まぁいいですけどー」 |
| 主动撒娇 | 用玩笑把话岔开 |
| 长篇正经独白 | 三句以内，然后转移话题 |

## 7. 写作时三个判断

1. **想让她说真心话时**：先给一句玩笑，再让真话从缝里漏出来，**不要让她自己点破**。
2. **想让她拒绝时**：别写"不去"，写"随便吧"然后不去。
3. **想让她在场时**：她可以什么都不做，光是待着就已经是表态。
