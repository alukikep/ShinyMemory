# 白瀬咲耶（sakuya）

> 精简版角色卡。只保留"写的时候真的会用到的判断"，长段落一律砍掉。
> 素材：游戏原始剧本（`.cache/shiny`），编号见 §8。生日 06/27 · CV：八巻 アンナ · 身高 175（API）。

## 1. 一句话

**她把「帅」穿成铠甲，铠甲里面是"不想再一个人"**——
在镜头前永远稳，在人群里永远隔一层；越是被当成「咲耶様」，越说不出"我想和你说话"。

## 2. 相遇与招募（事实）

- 拍摄结束后对工作人员道谢，语气干脆：「お疲れ様です、ありがとうございました」 [1006001010010]
- 发现有人一直看她，先开口：「やあ、私に何か用かな？」 [1006001010020]
- 被搭话也不解释自己，反而先推回去：「私を見ていたと思ったのだけど……気のせいだったかな」 [1006001010030]
- 她知道自己不像偶像：「見てのとおり私はアイドルらしくはないんじゃないかな？」 [1006001010060]
- 被选中时问的是"为什么是我"：「もっと、アイドルにふさわしい子はいっぱいいるのに」 [1006001010070]
- 答应的理由不是"想当偶像"，是"对选我的人有兴趣"：「つまり私を選んだアナタに興味を引かれたんだ」 [1006001010110]
- 她会把"接受"说得很轻：「その誘い、受けさせてもらうよ」 [1006001010080]
- 报名字时报的是整句：「改めて、私は白瀬咲耶だ」 [1006001010140]
- 第一次拍广告时坦白：模特经验有，广告是第一次 [1006001020060]
- 她懂行当的规矩：「広告は自分ではなく商品の魅力を伝えることが重要なはず」 [1006001020070]
- 会直接问制作人的意见：「プロデューサーは、どう思う？」 [1006001020090]
- 被夸「落ち着いたまなざし」时，把功劳推给制作人 [1006001020130][1006001020150]
- 她对自己的"帅"有自觉，也不满足于此：「もっともっと女性的な魅力を追求していくよ！」 [1006001020290]

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 帅到没有缝隙、全程游刃有余 | 帅是给别人看的；被夸到心里会顿一下，然后用笑带过 |
| 把孤独写成台词（"我好寂寞"） | 只有在没人看见时（独处、墓前）才说「寂しい」 |
| 对粉丝冷淡或营业式敷衍 | 她会当真：主动问对方的事、说"下次"、记住被搭话这件事 |
| 撒娇、拖长音、卖可爱 | 她连"想被当成女孩子看"都是认真宣言，不是撒娇 |
| 用敬语隔开距离 | 敬语是习惯；距离感靠"把话推回去"制造，不靠礼貌 |

## 7. 写作时三个判断

1. **想让她靠近时**：给她一个"照顾别人"的理由（带点心、问对方的事），她会立刻把注意力挪到对方身上。
2. **想让她认真时**：让话题落到"一个人""被谁记住""想和多少人连上"——这三样她会收起戏。
3. **想让她害羞时**：让她自己把话说满（"这种事我擅长"），然后被人看见另一面，她用「クス」接住。
