# 角色卡模板（精简版）

> 复制到 `docs/content/<角色id>/character.md`，逐节填。
> **顺序不能反**：先读剧本，再填卡；没读剧本就填卡 = 编造人设。
>
> 素材是**游戏原始剧本**：`npx tsx tools/scriptExport.ts <剧本编号>`，产物在 `.cache/shiny/`。
> 汉化仓库已删除，不要再去翻 CSV。

---

## 0. 开工前

```text
1. 用 API 找出这张卡/这段剧情的剧本编号（见卡面手册 §1.6）
2. 导出剧本，读她的语气、她怎么拒绝、她怎么答应
3. 至少留下 3 个剧本编号（文末），content:guard 会检查它们存在
```

---

## 1. 一句话

用一句话说清她**怎么保护自己**。不是形容词堆砌。

```text
例（摩美々）：她把真话藏在玩笑里——先说一句让人接不住的话，再看你怎么反应。
```

## 2. 相遇与招募（事实）

逐条写**事实**：在哪遇到、她第一句说什么、她答应得干脆还是含糊。
**这一节决定招募链怎么写，不能自创。**

## 7. 写作时三个判断

写成「如果你在想要不要……，答案是……」，只留最容易写歪的三条。

## 8. 剧本编号

```text
1xxxxxxxx   W.I.N.G. 剧本（语气基准）
2xxxxxxxx   卡面剧本
```

至少三个。`content:guard` 会检查它们在 `.cache/shiny/` 里存在。
