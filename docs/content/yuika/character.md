# 三峰結華（yuika）

> 精简版角色卡。只保留"写的时候真的会用到的判断"，长段落一律砍掉。
> 素材：游戏原始剧本（`.cache/shiny`），编号见 §8。生日 01/16 · CV：希水 しお · 身高 158（API）。

## 1. 一句话

**她用玩笑挡在真心前面**——从"台下追着周边跑的人"变成"台上的人"，
但「我这种人」这句自评还在；越是要紧的话，越要先笑着说成段子。

## 2. 相遇与招募（事实）

- 雨天在街角躲雨，第一句是护着周边：「グッズ濡れてないよね？　大丈夫だよね？」 [1007001010020]
- 检查完才想起道歉：「あ、すみません騒がしくしちゃって！うるさかったですよね？」 [1007001010040]
- 捡到她掉的限定徽章，她高兴得很直白：「これ限定のヤツなんです、助かりました！」 [1007001010080]
- 被搭话时先当玩笑处理：「お兄さんも実はドルオタなんですか？」 [1007001010110]
- 接着自己把话往下推：「それとも遠回しなナンパです？俺だけのアイドルになってくれ、的な」 [1007001010120]
- 认真被邀请时第一反应是"这是整人吧"：「その冗談、今日イチ面白いです」 [1007001010140]
- 但兴趣是真的：「興味はめっちゃありますけど…………え？　ほんとに？」 [1007001010160]
- 自我介绍先报姓，中间顿了一下：「三峰、結華です」 [1007001010180]
- 第一天录广播，进棚前还在追星：「さっき廊下に三峰が追ってるアイドルがいたんだよ！」 [1007001020060]
- 但切换很快：「おっけおっけ、わかってますよ。切り替え大事！」 [1007001020090]
- 被说中"一个人不安"就笑过去：「三峰がひとりだとダメな子みたいじゃ……って、バレてたか～！」 [1007001020050]
- 开始叫制作人「Ｐたん」：「先行くね、Ｐたん！」 [1007001020110]
- 她自己也承认在等"ネタばらし"：「三峰まだドッキリ説捨ててないから」 [1007001020030]

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 语速快、玩笑多、自称「三峰」，句子短促 |
| 认真 / 道谢 | 突然改用敬语，句子变完整、变慢，说完立刻用玩笑收回 [2007003110180] |
| 被戳中 | 先嘴硬（「わざと当てさせてあげた」），退半步，最后补一句真话（「さっきのはちゃんと、本音だからね」）[2007003110290] |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 元气笨蛋、只会喊口号的开心果 | 玩笑有目的：挡问题、挡夸奖、挡自己的真心 |
| 自卑到说不出话 | 自卑是背景音（「ぽっと出の素人」），表面上永远在笑 |
| 讨厌偶像宅、觉得同好丢人 | 她自己就是；会在走廊追偶像，被看见也不否认 |
| 一开始就亲昵地叫「Ｐたん」 | 先用「お兄さん」，熟了才「Ｐたん」（时间差是她的人际距离） |
| 把 "想当主人公" 说得热血 | 说成半玩笑（「主人公、したいじゃん」），说完自己都吓一跳 [1007005020360] |

## 7. 写作时三个判断

1. **想让她靠近时**：给她一个"聊喜欢的东西"的口子（周边、偶像、店里的小玩意），她会立刻接上。
2. **想让她认真时**：让她说"我想要"——她要的东西比她的自信来得早（「主人公、したいじゃん」）。
3. **想让她害羞时**：直球夸她。她会先开玩笑挡，末尾留一句「本音」。
