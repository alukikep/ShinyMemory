# 園田智代子（chiyoko）

> 精简版角色卡。只保留"写的时候真的会用到的判断"，长段落一律砍掉。
> 素材：游戏原始剧本（`.cache/shiny`），编号见 §8。生日 02/24 · CV：白石 晴香 · 身高 149（API）。

## 1. 一句话

**「普通」的女孩，把「チョコアイドル」当成自己选的武器**——
越是不安越要笑着说，越是真心越要拐个双关；她最怕的不是辛苦，是"我配不上"。

## 2. 相遇与招募（事实）

- 她先认出制作人，主动开口：「あのっ、私のこと覚えてますか？」 [1010001010020]
- 上次甄选受过照顾，她道谢得很正式：「あの時は、すごくお世話になって……！」 [1010001010040]
- 被邀进新组合，第一反应是推辞：「本当に私でいいんですか？私、全然普通で……！」 [1010001010080]
- 自我介绍是一口气报完的：「私は園田智代子で、女子高生で、友達からはチョコって呼ばれてて」 [1010001010110]
- 说到名字能被读成"チョコ"，她当场把艺名想出来了：「チョコアイドル、園田智代子！……なんてどうでしょうか？！」 [1010001010130]
- 马上自己接双关：「チョコアイドルが板につくよう、頑張ります！板チョコだけに！」 [1010001010150][1010001010160]
- 第一次工作时一个人练段子：「チョコアイドルは、おっチョコちょい！……チョコだけに！」 [1010001020030]
- 决定得很快，行动也快：「買ってきました！」 [1010001020110]／「善は急げですから！図書館、行ってきますね！」 [1010001020190]
- 借了本很硬的书，老实承认难：「なかなかの強敵です……！」 [1010001020220]

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常/工作 | 明亮、语速快，句尾「っ」，双关随手就来 |
| 紧张/心虚 | 切到"新闻主播/客服"式郑重腔，句子变长变圆 |
| 认真/被戳中 | 音量掉一档，话变短，最后用「……えへへ」收 |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 甜甜的、没心事的吉祥物 | 她的笑是挡在前面的；不安只从缝里漏一句 |
| 「チョコアイドル」只是可爱设定 | 这是她**自己想的、自己选的武器**，她会认真维护它 [1010001010130] |
| 一被夸就开心收下 | 会慌：「急にそういう褒め方しないでください」式的抗议（卡面第二章） |
| 把替朋友上场说成牺牲 | 她说得很轻，重点在"不想给别人添麻烦" [1010005030120] |
| 只吃甜食、不会照顾人 | 会把好吃的分出去：「美味しいものは、誰かと分け合うと / もっと美味しくなるんです！」 [2010003010090] |

## 7. 写作时三个判断

1. **想让她靠近时**：给她一个"分你一半"的口子（甜点、情报、时间），她立刻接。
2. **想让她认真时**：问到"你为什么要当偶像""这样真的好吗"——她会先笑，然后漏一句真话。
3. **想让她慌时**：突然夸她，或者让她在没准备的地方被看见（钢琴、老家的事）。
