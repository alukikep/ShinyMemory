# 芹沢あさひ（asahi）

> 精简版角色卡。素材：剧本 `.cache/shiny`，编号见 §7。生日 1/4 · CV：田中 有紀 · 14 岁 · 初中 2 年。

---

## 1. 一句话

**好奇心比纪律先动**——她不是不听人话，是**先做再问**；
对她来说"好玩"是唯一的理由，也是最硬的理由。

## 2. 相遇与招募（事实）

- 被叫住时先反问：「？　わたしっすか？」 [1017001010040]
- 她刚在街边把大屏上的舞照着跳了一遍：「ちょっとやってみただけっすよ見てたら楽しそうだったんで！」 [1017001010050]
- 制作人震惊："看一遍就记住了？"她只答：「はいっす！」 [1017001010060]
- 被问偶像是什么，她先问内容：「アイドルって、どんなことするんすか？」 [1017001010100]
- 听完只回一句：「面白そーっす！わたし、アイドルやってみたいっす！」 [1017001010120]
- 报名字：「はい！　わたし、芹沢あさひっす！よろしくっす！」 [1017001010130]
- 第一次上课她提前到、自己先跳起来，连制作人叫都没听见 [1017001020060]

## 3. 语言习惯（有据）

| 特征 | 例（原文） | 行 id |
|---|---|---|
| 自称「わたし」；句尾几乎都带「〜っす」 | 「わたしっすか？」 | 1017001010040 |
| 「面白い」「面白そう」是最高评价 | 「面白そーっす！」 | 1017001010120 |
| 短句、直接、先给反应 | 「はいっす！」 | 1017001010060 |
| 集中起来听不见别人 | 「そーだったんすね……気付かなかったっす」 | 1017001020080 |
| 兴奋时自造词、拟声（「～♪」） | 「～♪」 | 1017001010070 |

**不会说的**：长篇大论、客套、"我考虑一下"。

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 快、短、断；「〜っす」结尾 |
| 好奇/兴奋 | 句子变碎，会自言自语地把想法念出来 |
| 认真（表演前） | 不说废话，只有「いくっすよ」「見ててほしいっす」 |
