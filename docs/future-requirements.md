# 未来需求记录

## 1. 活动目标规则

当前规则：

```text
地点页：无偶像对象的制作人/生活行动
偶像互动页：需要明确偶像对象的行动
```

已实现：

- `ActivityDef.target?: 'none' | 'present-idol'`
- `free` 标记为 `present-idol`
- 地点页过滤 `present-idol` 活动
- 偶像互动页展示当前在场偶像的 `bond` 活动
- 活动命令显式携带 `idolId`

未来规则：

1. **地点页行动作用于所有在场偶像时，不做额外选择**
   - 行动直接作用于当前地点所有符合条件的在场偶像。
   - 不弹出目标选择器。
   - 如果当前地点没有符合条件的偶像，行动隐藏。
   - 每个目标分别应用效果和结果文本。

2. **需要选择特定偶像的活动放在偶像交互页**
   - 例如自由时间、单独吃饭、单独散步、关系剧情。
   - 目标由进入偶像页时确定。
   - 不在地点页显示多目标选择。

3. 未来可增加：

```ts
target?: 'none' | 'present-idol' | 'all-present-idols' | 'selected-idol';
```

其中：

- `all-present-idols`：地点页行动，作用于当前地点所有在场偶像。
- `selected-idol`：仅在偶像交互页出现。

## 2. 制作人属性

未来会加入制作人自身属性，例如：

```text
摄影能力
体力能力
口才能力
```

要求：

- 与偶像属性一样有等级/经验或数值成长。
- 可以作用于事件判定、行动判定、工作结果、对话条件。
- 需要新增条件类型，例如 `producerAttributeAtLeast`。
- 需要新增效果类型，例如 `producerExp`。
- 需要决定制作人属性是 Rank + EXP，还是数值 + 阈值。
- 需要内容审查和 schema 校验支持。
- 需要 UI 展示和存档迁移。

当前不实现，只记录需求。

## 3. 当前边界

- 自由时间已从地点页移到偶像互动页。
- 正式内容仍然只有真乃。
- 事件、工作、商店、物品正式内容仍为空。
- 制作人属性尚未进入 `GameState`、条件系统或审查系统。
