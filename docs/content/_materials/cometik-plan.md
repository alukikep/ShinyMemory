### 2.2 羽那・はるき 的招募**不依赖** ルカ，但**时间上**在她之后

- 羽那：高中同学把她的视频发上网走红，制作人从东京到冈山，在会客室问她

- はるき：美术高中、映像部、替乐队弹贝斯；在艺术集会上发传单时被制作人的话推了一把，

  **ルカ 先入所，羽那・はるき 同一个月入所**，然后才有 CoMETIK 的邀约。

### 3.1 为什么她肯让制作人站到门口（这一环不能省）

原作 `490103908` 的门口**是三个人**，不是两个人。经纪人当时就在场，三句关键台词都当着她说的：

| 台词 | 交代了什么 |
|---|---|
| 「移籍は、あくまで彼女がうんと言ってくれればの話で」 | **移籍已经在谈**——制作人不是路过的人 |
| 「食事を届けるように、約束していたので」 | 看护是她托付的 |
| 「あなたのことを、とても大事に思っている方から」 | 这里的"方"就是她 |

连起来的因果是三件事叠在一起：**致敬演出当晚两边的人碰上了（`400105808` 终章，经纪人「美琴を貸してくださって」）→ 事务所那边已经放弃她、283 在谈接手（同章 社長「あれはラストシングルだ」「始めようというのか」）→ 经纪人出国前把送饭交给他**。
少掉第一环，"制作人为什么站在这个门口"就只能靠旁白交代——所以第 1 步必须让经纪人**在场**。

她在游戏里没有 `ActorDef`（不排班），署名走 `SPEAKER_NAMES.luca_manager`（`src/core/labels.ts`），
否则 `speakerId` 解析不到人会渲染成**空名字**。

`490103901`〜`907` 七段是 ルカ 一个人在房间里的独白，没有玩家在场，
**不能做成行动**——只在第 1 步的旁白里带过。

"她答应加入 283"原作也留白（`W.I.N.G.編` 开始时她已在籍），所以链停在"她放下剪刀"，
`complete.status = recruited` 只是把结果落到状态上。

卡面 `【broken shout】`（`202600401`〜`411`，5 章已上线）：刚移籍、工作断了、
采访说不出话、live 音响全坏——正好接在她进门之后。五章串成一条线：
**工作断了 → 她不说 → 被问到说不出话 → 在坏掉的设备上喊完 → 别人替她说出她说不出的那句**。

她的专属行动是 `陪她在练习室待到关灯`（练习室 18:00–23:00，体力 6，信任 +5 / 舞蹈 +1 / 压力 −4），
话题 8 条（今天 / 练习 / 吃饭 / 老家 / 美琴 / 粉丝 / 手机 / 舞台），
训练后事件 3 条（唱到第三首就听不见 / 练到站不稳也不肯停 / 不知道自己在用什么表情）。

排班要点：她**几乎不来事务所**（一周只有周三下午），周五晚上在会场，
周六上午双周轮换站前／商店街；写事件地点时要对着这张表挑日子，
`luca.spec` 一开始就踩过一次——周五 19:00 她在 `hall`，不在 `practice_room`。
