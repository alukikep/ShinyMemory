# 地点入口（区）

> 已实现（2026-10-31）。**规则以本文为准。**

---

## 1. 模型

```text
入口（kind: 'area'）
  ├ members: ['practice_room', 'studio']
  └ 进入 = 0 分钟移动（不耗时间、不触发事件）

成员（原来的地点）
  └ 行动 / 事件 / 日程 / 剧情 / 章节继续引用它们的 id
```

- 地图上只画**入口 + 独立地点**（不属于任何入口的，如事务所、家）。
- 玩家在成员地点时，地图的高亮落在它所属的入口上。
- 内容**只引用成员 id**；入口 id 不进门。

现在的入口：

| 入口 | 成员 |
|---|---|
| `ekimae` 朝雾站前 | 车站（站前一带，含喫茶店）、商业街、唱片店 |
| `studio_district` 青叶练习街区 | 练习室、录音棚 |
| `seaside` 滨风海岸 | 公园、泳池、医院 |
| `university_district` 望丘台 | 望丘大学（以后可加旧书店、学生食堂…） |
| 独立 | 事务所、事务所屋顶（office 走楼梯 5 分钟）、家、学校（不可达） |

**加一个地点**：先想清楚挂在哪一带。新的一带 = 新入口（`kind: 'area'`）+ `members`
+ 该入口的坐标 + 一条 0 分钟边 + 把它接进步行网络（`productionMap.test` 会验）。
只是往已有的一带里加一处，就只加成员 + 0 分钟边。

---

## 2. 交通规则（2026-10-31 定）

| 方式 | 时间 | 费用 | 范围 |
|---|---|---|---|
| 步行 | 跨地区 **15 分钟**（每个相邻边） | 0 | 只到相邻节点 |
| 公共交通 | **5 分钟** | ¥100 | 全图：任意地点 → 任意入口/独立地点 |
| 进楼 / 出楼 | **0 分钟** | 0 | 入口 ↔ 成员 |

- 出租车已取消（只保留 `kind: 'bus'` 的公共交通）。
- 公共交通的**上车点不限**：人在楼里也能直接坐车走。
- 目的地只列入口与独立地点——不会出现"坐车去练习室"。
- **剧情收尾搬家**（`step.endLocationId`）：章节演完把玩家放到另一处，**0 分钟**、只搬玩家。
  用于"旁白换场"的一次性场景；目标必须是真实地点，不能写入口（`content:anchors` 会拦）。

---

## 3. 界面

- **入口页**：描述这一带 → `[进入 练习室] [进入 录音棚]`。
- **成员页**：`[回到青叶练习街区]` + 这一处自己的行动。
- **进楼后地图栏隐藏**（地图只能点入口，留着会让人以为按钮坏了）；回入口页再显示。
- 地图提示徽章挂在入口节点上（章节在成员地点，也显示在所属入口）。
- **剧情对话顶栏**显示 `STORY ｜ 章节名 ｜ 一带 · 地点`——玩家任何时候都知道自己在哪。
  独立地点只显示自己（没有一带）。

## 5. 写内容前的检索

```bash
npm run content:where -- seaside        # 入口：里面有什么、可做什么、哪些剧情在这
npm run content:where -- pool           # 成员：会告诉你在哪个入口里
npm run content:where -- --route office seaside   # 跨地区路线与步行分钟
npm run content:where -- --idol kiriko            # 她一天在哪几个地区
```

---

## 6. 新角色接入注意

- 她的常去地点如果是"楼里的房间"（练习室/录音棚/泳池），**不需要**新建入口——先用现有的；
- 日程写成员 id（`practice_room`），不要写入口 id；
- 专属行动的地点也写成员 id；
- 如果她需要**新的一带**（例如剧场、电视台），再加一个入口 + 成员，不要直接往地图上塞孤立节点。

## 7. 已知取舍

| 取舍 | 说明 |
|---|---|
| 多点一次才能做事 | 入口页把成员做成大按钮；这是地图可读性的代价 |
| 跨地区步行统一 15 分钟 | 距离感被抹平，换来公交（5 分钟）有明确价值 |
| 入口页没有偶像 | 人都在成员地点里；入口只是走廊 |
| 车站不再是枢纽 | 公共交通全图可用后，车站只作为人流多的地点（跑腿、街拍） |
