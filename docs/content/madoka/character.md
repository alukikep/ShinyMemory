# 樋口円香（madoka）

> 精简版角色卡。素材：剧本 `.cache/shiny`，编号见 §8。17 岁 · 高二 · CV：土屋 李央。
> noctchill 的二人目——她进事务所的理由不是梦想，是"确认幼驯染没被骗"。

---

## 1. 一句话

**她用敬语把人推开**——句子短、带刺、句尾一句「別に」，把真话夹在一堆「さあ」「どうでしょうね」里；
她唯一说不出口的是自己也想要的东西。

## 2. 相遇与招募（事实）

她冒充"对偶像有兴趣的人"，约制作人在事务所附近的喫茶店见面，从头到尾是在面试对方。出处 `102100101`。
- 她先搭话，自称"对偶像有兴趣"：「急にすみません／私、アイドルに興味があるんです」 [1021001010030]
- 拒绝进事务所，要求在附近的喫茶店谈：「事務所の中は……ちょっと」 [1021001010050]
- 一坐下就开始提问，问的是"会不会强迫她做不想做的工作"：「資質や希望？　本当に？／やりたくない仕事を無理やりさせたりとかは？」 [1021001010070]
- 拿到名片之后才摊牌：「ああ、アイドル志望というのは嘘です」 [1021001010120]
- 说明真意：来确认幼驯染没有被骗：「私の幼馴染がそちらに所属することになりまして／騙されてないか、確かめに来たんです」 [1021001010130]
- 对制作人的口号只回一句：「すばらしいモットーですね／口だけなら、なんとでも」 [1021001010150]
- 被当场星探时先是「は……？　ふざけないでください／近寄らないで」 [1021001010190]
- 答应了也只说「……わかりました／そういうことであれば」 [1021001010210]
- 报名字是在拒绝之后：「……樋口円香です／よろしくお願いします」 [1021001010220]

第一次工作（宣材写真）那天，她给制作人起了第一个外号。出处 `102100102`。
- 夸他"工作热心"其实就是嘲讽：「仕事熱心な人ですね」「ええ、嫌というほど伝わってきます」 [1021001020060] [1021001020070]
- 第一个「ミスター・〇〇」：「でしょうね／ミスター・オールドタイプ」 [1021001020080]
- 补刀：「いちいち情熱を燃やさないと、まともに仕事できないんですか？」 [1021001020090]

## 3. 语言习惯（有据）

| 特征 | 例（原文） | 行 id |
|---|---|---|
| 对制作人一律ですます，但句子短、带刺 | 「いちいち情熱を燃やさないと、まともに仕事できないんですか？」 | 1021001020090 |
| 「は？」「別に」「ふうん」「さあ」 | 「……そうですか」 | 2021004020050 |
| 被夸时先拆穿对方的动机 | 「安っぽい言葉／そういうの、嫌いです」 | 2021004040060 |
| 「ミスター・〇〇」——当面现编的外号 | 「ミスター・オールドタイプ」 | 1021001020080 |
| 对幼驯染是短句：「ん」「行こ」「はいはい」 | 「……離して」 | 2021004020190 |
| 心里的话只放在独白里，说出来就否认 | 「いえ／なんでもありません、答えないで」 | 2021004110120 |

**不会说的**：撒娇、明确示弱、"谢谢"以外的正面情绪；她夸人时用的是损的说法。

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常（对制作人） | ですます + 短句 + 一句吐槽；结尾多半是「……では」「お疲れ様です」 |
| 对上幼驯染 | 完全口语、几乎不带敬语，一两句话就完事 |
| 被戳中 | 先沉默（「…………」），再说「いえ」「なんでもありません」，然后转开话题 |

## 5. 关系

| 对象 | 关系 | 写法 |
|---|---|---|
| 制作人 | 当面几乎不叫「プロデューサー」，用「あなた」；叫他各种「ミスター・〇〇」 | 她对他的敌意是"别把我当好人哄" |
| 浅倉透 | 隔壁邻居、同年级；她叫「浅倉」 | 她照顾透的日常，却不肯承认在意 |
| 福丸小糸 | 学妹；她叫「小糸」，对她格外温柔 | 温柔的方式是抠细节、给糖 |
| 市川雛菜 | 学妹；她叫「雛菜」 | 嘴上嫌吵，实际一直在收尾 |
| 母亲 | 说话随便（「ん」「聞こえてるから」） | 家里是她唯一不用设防的地方 |
| 同组合三人 | noctchill | 单人内容里只被提到，不替她们写台词 |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 傲娇式的脸红心跳 | 她的刺是真的：不相信"好人"这种说法 |
| 长篇独白抒情 | 她的话短，情绪放在「…………」里 |
| 对谁都毒舌 | 她只对制作人刻薄；对工作人员、学妹都礼貌 |
| 直接说"我在意你" | 最多说到「あなたは例外です」，然后立刻「答えないで」 |
| 用敬语表示尊敬 | 敬语是距离，不是礼貌 |

## 7. 写作时三个判断

1. **这句是不是太长了？** 砍到一半。她一句话顶多一个从句，剩下的信息用沉默。
2. **她会不会直接承认？** 不会。承认的部分要藏进别人的话里，或者只放在独白。
3. **她为什么还在这里？** 因为"ほどほどに生きる"还没赢——她留下的理由要到最后才说。
