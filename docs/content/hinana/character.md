# 市川雛菜（hinana）

> 精简版角色卡。素材：剧本 `.cache/shiny`，编号见 §8。15 岁 · 高校 1 年 · CV：岡咲 美保。
> noctchill 最后一人——她当偶像的理由最简单，也最难反驳："因为开心"。

---

## 1. 一句话

**她只选让自己幸福的那条路，而且从不为此道歉**——用「雛菜」自称，句子尾巴拖得长长的，
被要求"再努力一点"时会先问一句"为什么"。

## 2. 相遇与招募（事实）

面试是她自己来的，理由只有一个：透先辈要当偶像。出处 `102300101`。
- 一进门就自来熟：「わ～♡今日はよろしくお願いします～！」 [1023001010010]
- 自我介绍：「は～い♡市川雛菜、高校１年生です～～～」 [1023001010020]
- 动机：「透先輩がアイドルやるって聞いて～……」「すっごくいいな～、雛菜もやりたいな～って思って来ました♡」 [1023001010030] [1023001010040]
- 特技答得含糊：「特技～……？ん～なんでもそれなりにできる～！」 [1023001010050]
- 被说"偶像不只有开心的事"，她直接挑：「え～、大変なのはやだ～……」「あっ！　雛菜は楽しい担当がいい！」 [1023001010080] [1023001010081]
- 她的信条：「雛菜はどんな時でもね／楽し～く、しあわせ～に過ごすの」 [1023001010130]
- 结论：「じゃあ雛菜、アイドルに向いてるね？」 [1023001010150]
- 面试最后一句：「雛菜、プロデューサーのことすきかも～～～！」 [1023001010200]

第一次去练习室看课，她在课上还回头喊。出处 `102300102`。
- 看到制作人来看，兴奋地喊：「プロデューサー見てた～～～？／褒められちゃったよ～～～！」 [1023001020130]
- 被提醒"上课中"，她说理由是「だって、うれしかったから～」 [1023001020140]
- 反过来要求：「それじゃあプロデューサーは／雛菜に集中しててね～？」 [1023001020150]

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 拖长音、「～♡」、句子随想随说，常自己岔开话题 |
| 认真 / 被说中 | 拖长音消失，句子变短，只留「…………」和一句很直的话 |
| 不高兴 | 不吵，只是「今日のプロデューサー、きらい～～～」，然后走开 |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 任性、没心没肺 | 她的"选幸福的"是有边界的：不做不想做的事，但也说"稍微辛苦一点也可以" |
| 傻乎乎、听不懂话 | 她听得懂，只是不接；岔开话题是她的处理方式 |
| 元气到没有阴影 | 她会突然安静，问"什么时候会结束呢" |
| 满口敬语 | 对谁都偏随意，只有对工作人员会用です・ます |
| 拿"幸福"当口号喊 | 这个词对她是很具体的东西：甜食、天气、身边的人 |

## 7. 写作时三个判断

1. **这句尾巴要不要拖长？** 拖长是她的默认；一旦不拖了，说明她认真了。
2. **她会不会照做？** 不会照做，但也不会拒绝——她会把要求换成自己想要的形式。
3. **她真的没在想吗？** 不是。她只是在别人问"以后怎么办"的时候，先想起"现在开心"。
