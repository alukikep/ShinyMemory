# 斑鳩ルカ（luca）

> 精简版角色卡。素材：剧本 `.cache/shiny`，编号见 §8。20 岁 · CoMETIK · 已出道多年。
> 她是"被捡回来的人"——不是新人，也不是重新开始，是**第一次允许别人站在旁边**。

---

## 1. 一句话

**她把"被夺走"当成世界的规矩**——话短、火气大、四分之一台词只有省略号；
对谁都用「アンタ」「オメェ」，对粉丝却会平静地说「うん」「ありがとう」。

## 2. 相遇与招募（事实）

她不来事务所，也不接受面试。是制作人一次次去她家门口，把便当挂上门把。出处 `490103908`〜`910`。
- 门里先问的是「食べ物…………？」，认出来之后是「な…………／…………んだよ…………オマエ……………………」 [4901039080010] [4901039080030]
- 提到"约好了要给她送饭"时，她反问的是「………………約束────────？」——她不知道有人替她托付过 [4901039080050]
- 她点名的东西是「『ママのナポリタン』」，理由先说在前面：「オメェに……絶対用意できねェもの」 [4901039090080] [4901039090090]
- 她自己也说得清那是什么：「どんどんいろんなもんが奪われて……なくなってく」 [4901039090120]
- 发烧那晚抓着剪刀、把头发剪了下来；制作人喊「やめてください……それを置いて…………！」 [4901039100200]
- 最后崩出来的是「もう…………奪うなよ………………」——她要的不是帮助，是**别再拿走** [4901039100210]

## 6. OOC 对照

| 不能写 | 为什么 |
|---|---|
| 长篇解释自己的心情 | 她的台词里 63% 带「……」，解释性长句几乎不存在 |
| 主动撒娇、主动求助 | 她要的是"别夺走"，不是"帮帮我" |
| 对粉丝冷淡 | 她对粉丝是全书最温和的一处 |
| 把妈妈的事说出口 | 她守了十几年的约定，只在被逼到墙角时才漏一句 |

## 7. 写作时三个判断

1. **这句话能不能再短？** 能省的主语、能省的动词都省掉，剩下的才是她。
2. **她是在赶人还是在留人？** 她嘴上赶人时，动作往往相反（门开一条缝、便当收进去）。
3. **她有没有在解释？** 一旦开始解释，就写错了——改成沉默或一句反问。
