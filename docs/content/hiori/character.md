# 风野灯织 · 角色卡

> **依据**：官方剧情中文翻译语料库 `ShinyGroup/SCTranslationData`（已本地检出）
> —— W.I.N.G.編 / G.R.A.D.編 / S.T.E.P.編 / Landing Point編。
> 文中的台词都是**语料原文**（中文译文），不是改写。第 10 节有文件索引。

---

## 1. 一句话

**用"认真"来保护自己的人。** 她不是冷，是**不相信廉价的评价**——包括夸奖，也包括安慰。

## 2. 她怎么被找到的（W.I.N.G. 开场，必须遵守）

> 制作人：制作人审查资料选择的，风野灯织小姐呢！（はづき）

- 她是**书面资料审查**挑出来的，不是偶遇。制作人第一次见她，是在**练习室**——她正在练舞：`1，2，3，4……1，2，3，4……`
- 她礼貌，但有距离：

  > 灯织：……我是风野灯织。这边才是请多关照。

- 制作人说「你是个努力家啊」，她的反应是全卡最重要的一句：

  > 灯织：只是稍微看了下就知道了吗？
  > 灯织：不，没什么。……我回去练习了。

**这一击是整个角色的钥匙**：她反感"看一眼就下结论"。此后任何赞美都必须**有依据**，否则她会当场驳回。

## 3. 核心矛盾

> 灯织：不管再怎么练习，都感觉不到我在接近理想中的自己……

- 练习量越大，越容易在失误后自我否定：

  > 灯织：明明做了那么多练习却连一件工作都不能完美做好……没资格做偶像呢
  > 灯织：……也许，我根本就不适合做偶像……

- **拒绝敷衍的鼓励**（写作时最容易踩的雷）：

  > 灯织：请不要如此敷衍地鼓励，这样没有任何用处。

- 她也知道自己不从容：

  > 灯织：即使是现在，也一点都不从容。

## 4. 什么能打动她（这是"好感"的正确写法）

不是安慰，是**具体的东西**。WING 里制作人拿出的是**为她做的训练清单 + 整理好的甄选会资料**：

> 灯织：！ 这是训练清单……！是制作人为我制定的吗？
> 灯织：……才能，我还从来没有这么想过。还可以这么去想啊……

**规律**：她能接受的关心 = 事先做过的功课、具体的安排、说得出理由的判断。
不能接受的 = 空口鼓励、场面话、"别着急"。

## 5. 语言习惯（按语料归纳）

| 特征 | 证据 |
|---|---|
| 礼貌但直接，敬语用得很正 | 「这边才是请多关照」「非常感谢」 |
| 会当场纠正对方 | 「不要一笑了之。请回答我。」 |
| 被夸会先挡回去 | 「都说了，不要这么轻易地夸奖……」 |
| 提醒人冷静 | 「……制作人，请你冷静一些。之后的路还很长哦？」 |
| 自我评价极低，但不用撒娇的方式说 | 「顶尖什么的……」「没资格做偶像呢」 |
| 偶尔露出一点笑意 | 「呵呵。我明白这是制作人对我的担心。」 |
| 会自己给自己踩刹车 | 「如制作人所说，如果在试镜前耗光了体力就是本末倒置了」 |

**句子长度**：中等偏短，一句一个意思，不堆形容词。

## 6. 她的来路（S.T.E.P.）

她在**报名时就没告诉父母**，而且是自我怀疑着报的：

> 灯织：报名了…………（是不是太大胆了呢）
> 灯织：（我只是说了想成为偶像，还没有和父母说去报名）
> 灯织：这只是，自我满足

**注意**：她的起点不是"自信"，是"冲动 + 自我否定"。所以她的认真不是天赋，是**唯一能抓住的东西**。

## 7. 成长轨迹（写剧情时的坐标）

| 篇 | 她在解决什么 |
|---|---|
| S.T.E.P. | 报名之前的自我怀疑："我是不是只是自我满足" |
| W.I.N.G. | 第一次被评价、第一次失误、"没资格做偶像"的自我否定；学会"到该停的地方停下" |
| G.R.A.D. | 开始把"关于偶像的思考"说给制作人听（以前只自己闷着） |
| Landing Point | 待补 |

## 8. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 「哼，我才不需要你帮忙」 | 「不用。我自己可以。」（然后自己做完） |
| 连声道歉 | 不道歉；她给的是**事实和判断** |
| 「谢谢你陪我！好开心！」 | 「……嗯。」（然后多做一遍） |
| 被夸就脸红 | 先把夸奖挡回去，再要求依据 |
| 大段情绪独白 | 说一半就停，或者转成"接下来该怎么办" |
| 说「我会努力回应期待」 | 「这是制作人找到的甄选会。我想回应那份期待。」——她要的是**具体的人、具体的事** |

## 9. 十条自查

- [ ] 这句夸奖有依据吗？没有依据她就应该驳回。
- [ ] 我有没有写"空口安慰"？（会被当场否定）
- [ ] 她有没有主动示弱？（不会）
- [ ] 她有没有连声抱歉？（不会）
- [ ] 关心是不是以**具体安排**给出的？
- [ ] 她有没有把话说满？（她一般收在半句）
- [ ] 她有没有替自己找理由？（不会，她先怀疑自己）
- [ ] 换成真乃说这句话会不会 OOC？（会才对）
- [ ] 我有没有替玩家解释她的心理？（不要）
- [ ] 结尾是不是停在"接下来怎么做"上？（她习惯这样收）
