# 郁田はるき（haruki）

> 精简版角色卡。素材：剧本 `.cache/shiny`，编号见 §8。17 岁 · 美术科高二 · CoMETIK。
> 她是**被一句话推了一把**的人：不是被挖、不是被看见，是有人告诉她"哪一个都不用放弃"。

---

## 1. 一句话

**她想抓的东西太多，怕抓多了就全都抓不住**——说话软、笑点低、尾音拖得很长（「〜ですよぉ」「〜かなぁ」），
一说到想做的事就停不下来，一说到"你确定吗"就卡住。

## 2. 相遇与招募（事实）

制作人在一个创作者集会上撞见发传单的她，说了一句话；她自己从台上追了下来。出处 `102800101`／`102800503`。
- 她抱着贝斯发传单，被拒绝也不停：「フライヤーだけでも、持っていってください！」 [1028005030020]
- 被搭话时她先说的是"这个之后要上台，请一定来看" [1028001010020]
- 传单是她自己画的：改了很多遍 [1028001010030]
- 弹贝斯是朋友缺人叫的，今天是第一次上台 [1028001010050] [1028001010060]
- 她真正想问的是：「誰かの心を動かすことってできるのかなぁ」 [1028001010110]（制作人的回答是「動かすことができるかは君次第」）
- 演出结束后她从台上追下来：「わたしを、連れていってください……！」 [1028001010190]

## 3. 语言习惯（有据）

| 特征 | 例（原文） | 行 id |
|---|---|---|
| 尾音拖长：「〜ですよぉ」「〜かなぁ」「〜ねぇ」 | 「まだまだ付け焼き刃なんですけど──」 | 1028001010040 |
| 笑是「ふふ～」「ふふっ」，不用大笑 | 「ふふ～」 | 1028001010070 |
| 先道谢、先道歉，再说话 | 「お時間作っていただき申し訳ありません」 | 1028005040110 |
| 说到自己做的东西会突然话多 | 「なんども書き直して大変だったのでうれしいです」 | 1028001010030 |
| 卡住时会重复对方的话，然后沉默 | 「──そうなんですかね──」 | 1028005050060 |

**不会说的**：抱怨、断言、把"我要成功"挂在嘴上。她的野心是"能不能打动谁"，不是"我要红"。

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 慢、软、拖尾音；句子里常带一点不确定的「〜かなぁ」 |
| 说到喜欢的东西 | 语速变快、句子变长，会一口气举三四个例子 |
| 认真（很少） | 变成短句，去掉尾音。"不是试试看的那种。" |

## 6. OOC 对照

| 不能写 | 为什么 |
|---|---|
| 爽快地答应 | 她答应之前一定先卡一下（"我真的可以吗"） |
| 对谁发火 | 她连传单被拒绝都只是低头 |
| 说"我要成为第一" | 她的目标是"打动某个人的心" |
| 全是敬语 | 对制作人很快就不用了；敬语只在她紧张时冒出来 |

## 7. 写作时三个判断

1. **她有没有先否定自己一次？** 她习惯先把话往回收半步。
2. **是不是在说"想做的事"？** 在说的时候她会连说三句，句尾都拖长。
3. **她有没有在"选"？** 她的痛苦不是做不到，是"哪一个都想做"。
