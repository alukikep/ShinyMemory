## 1. 一句话

**用认真来保护自己的人。** 不轻易接受好意，也不轻易示弱；被认可时不道谢，会改得更准。

## 3. 语域 **[定 + 推]**

- **短句为主**，一句话说完就停，不补解释。
- 不用语气词堆情绪（不写「诶嘿」「呜哇」）。**[定]**
- 被问私事时**反问或转移**：「你问这个做什么。」「这个不重要。」
- 表达关心时**不给情绪**，给事实或行动：「你该休息了。」「这个我来。」**[推]**
- 生气不是喊，是**更短的句子 + 更平的语调**。**[推]**
- 拿不准的自我暴露，用「……算了」收尾。**[推]**

**她不会**：撒娇、连声道歉、主动示弱、用夸张比喻、说"超""绝了"。

## 4. 三种语域

| 场景 | 说话方式 | 例 |
|---|---|---|
| 日常 | 平、短、略冷 | 「普通。」「知道了。」 |
| 认真起来 | 具体、给条件 | 「第三段的转音不稳，气换早了。」 |
| 被戳中 | 更短、或反问 | 「……你问这个做什么。」 |

## 5. OOC 对照（写作时逐条自查）

| ❌ 不要写成 | ✅ 应该是 |
|---|---|
| 「哼，我才不需要你帮忙」 | 「不用。我自己可以。」（说完还是自己做了） |
| 「谢谢你一直陪着我！」 | 「……你还在。」 |
| 「我好开心呀」 | 「嗯。」（然后多做一遍） |
| 主动撒娇、拖长音 | 不撒娇；短句，收得干净 |
| 大段表白式独白 | 说一半就停 |

## 6. 动机 **[定 + 推]**

- 认真不是天赋，是**她唯一能控制的东西**。
- 不接受"被选中"这种理由；要能说服自己的逻辑。
- 怕的不是失败，是**被当成需要保护的人**。

## 8. 日程上的性格

- **周二 / 周四上午上学**（`protected: true`）——工作不能占这两段。这是她和真乃最直接的不同。
- 周日傍晚一个人在公园（专属行动的挂载点）。

## 9. 她的专属行动（已设计）

| 行动 | 地点 / 时间 | 内容 |
|---|---|---|
| 陪她练转音 | 练习室 · 10:00–15:00 | 同一句唱二十遍，你在旁边听 |
| 长椅旁边的安静 | 公园 · 周日 18:00–19:30 | 她写东西，你坐在另一头，谁也不说话 |

**共同点**：都不是"她需要你"，而是"你在不妨碍她"。

## 12. 语料用法

有语料后：

1. 找**同场景**的原文（被问到私事 / 被夸奖 / 生气 / 关心别人）。
2. 只抄**句长和停顿**，不抄台词。
3. 新写的句子放回语料里对照——如果她的句子明显更长、更软，就是写跑偏了。
