## 1. 地点：透这一轮不需要新地点

把透的 7 本剧本按场次过了一遍，每一场都能落在现有地点里：

| 场次 | 出处 | 落点 |
|---|---|---|
| 公交站搭话、递名片 | `102000101` | `station`（站前，含公交站牌） |
| 事务所签约 | `102000101` | `office` |
| 电视台走廊挨个打招呼 | `102000102` | `studio`（第一次进摄影棚那天） |
| 事务所问卷 | `202000401` | `office` |
| 夜里的公交（窗户、降车按钮） | `202000402` | `station`（旁白带过"回程的公交上"） |
| 练习室看手机里的电影 | `202000403` | `practice_room` |
| 食堂「AA 吧」 | `202000404` | `station`（站前的食堂／喫茶店） |
| 公园黄昏、星星 | `202000411` | `park` |

**没有为"公交车上"单独建地点**：它不是能反复回去的地方，用旁白 + `station` 承载即可
（同一条原则见 [location-portals.md](../../systems/location-portals.md)）。

円香、小糸、雛菜的剧本还没读，**她们的地点落点等各自开轮再定**，不预判。

## 3. 首卡结构（5 章 = 5 段 commu）

`【10個、光】浅倉透` 本身是 5 节，正好一卡一链五步；首尾是同一条线：

```text
1 问卷「一生のうちにやりたい10のこと」（三分支）
2 夜里的公交——白天也亮着的东西
3 练习室的电影（三分支）
4 食堂「这里就 AA 吧」（三分支）
5 公园的星星——她把那颗星写进问卷
```

分支数按剧本结构核过：401/403/404 各 3 支，402/411 无分支；
每支都演到章末，不合流（playbook §2 的例外条款）。

## 4. 组合层面的注意

noctchill 四人是幼なじみ，戏大量同场（生配信、花火大会、派对）。
和之前一样：**单人内容里不替另外三人写台词**，只让她们被提到（透会叫「樋口」「小糸ちゃん」「雛菜」）。
四人互动留给组合层的 cast 事件。
