## 1. 一句话

**两副面孔是同一个人**——对外是"可爱的ふゆ"，对内（制作人、あさひ、愛依）是毒舌的"ふゆ"；
她不是装，是**怕被讨厌**，所以先把讨人喜欢的那面递出去。

## 2. 相遇与招募（事实）

她在站前盯着海报看，被搭话后用的是营业式的回应（整段的出处是 `101800101`，逐句行 id 见下）。
- 自我介绍用"可爱的ふゆ"：「はい！　ふゆは、黛冬優子って言います『ふゆ』って呼んでください」 [1018001010190]
- 应承得滴水不漏：「はい、期待に応えられるよう精いっぱい頑張ります♡」 [1018001010220]
- 制作人注意到她"一瞬露出的表情"不同于营业笑脸 [1018001010200 后]
- 第一次拍摄现场对staff全是「えへへ、そんなことないです」 [1018001020030]
- 转头对制作人就换了语气：「もう、冬優子じゃなくて『ふゆ』って呼んでくださいって言ってるのに」 [1018001020060]
- 她也会直接问：「──本当に、ふゆがアイドルになれると思いますか？」 [1018001020040]
