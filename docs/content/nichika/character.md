# 七草にちか（nichika）

> 精简版角色卡。素材：剧本 `.cache/shiny`，编号见 §8。16 岁 · 高校 1 年 · CV：紫月 杏朱彩。
> SHHis 的一人目——她不是被发掘的，是自己把制作人堵在唱片店后台求来的。

---

## 1. 一句话

**她把自己放在"平凡"那一格里，然后拿这句话当鞭子**——ですます＋拖长的句尾是她的礼貌，
「うーわー」「やばい」和一句带刺的吐槽才是她的真话；越是在意，越要刺一下。

## 2. 相遇与招募（事实）

她把制作人骗到唱片店后台，然后求他看自己跳舞。出处 `102400101`。
- 她用"经理叫你"当借口把人带走：「マネージャーがお呼びするようにって……バックルームまで、お願いできますか？」 [1024001010040]
- 说谎之后立刻道歉：「嘘をついてごめんなさい……！　私、アイドル志望で────」 [1024001010070]
- 真正的请求：「歌とダンスを、見てほしいんです…………！　お願いします────！」 [1024001010080]
- 被婉拒时的底牌：「どんなことだってやります！」 [1024001010100]
- 急了会威胁：「────お、大声を出しますよ……！」 [1024001010110]
- 报名字时编了一个假名：「八雲……ななみです……」 [1024001010140]，被胸牌上的「七草」拆穿
- 求保密：「お姉ちゃんには、秘密にしてください──────！」 [1024001010160]
- 在屋顶喊到有回声，为的是"收回不了"：「七草にちか、ごーうーかーくーーーー…………！」 [1024001010170]
- 理由：「取り消せませんよ……！　お姉ちゃんにも取り消せないように、大声出してるんです！」 [1024001010180]

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | ですます＋拖长＋一句吐槽；语速快，话题跳 |
| 被说中 / 受伤 | 先笑（「あははっ」），再补一句刺，最后把责任推给自己 |
| 认真（很少） | 拖长音消失，句子变短、变直；说完会要求保密 |

## 7. 写作时三个判断

1. **这句是不是太软了？** 是就加一根刺。她的温柔永远包在带刺的句子里。
2. **她会不会说"我很努力"？** 不会。她会说"我这种凡人"，然后继续练。
3. **她为什么在这里？** 因为她不想只是"风景"——这句她只在被逼到墙角时才说。
