# 角色卡模板

> 复制这份文件到 `docs/content/<角色id>/character.md`，逐节填。
> **顺序不能反**：先读语料，再填卡；没读语料就填卡 = 编造人设。
>
> 语料仓库：`ShinyGroup/SCTranslationData`（已 clone 到工作区外层目录）。

---

## 0. 开工前必须做的三件事

```text
1. 打开 data/story/<日文名>/W.I.N.G.編/，读「相遇」那一章（通常是 公園の歌声 / クールで真面目な女の子 之类）
2. 读 S.T.E.P.編 的第一章（出道之前，能看到她的动机）
3. 读对你接下来要写的内容最接近的那一章（受挫 / 加练 / 工作失误 / 组合关系）

读完再动笔。读 10 行就有语感，比凭印象写一小时强。
```

## 11. 语料索引

> **格式要求**：一行一个**完整路径**（`data/story/<角色>/W.I.N.G.編/xxx.csv`）。
> `npm run content:guard` 会解析这些路径并检查文件是否存在——路径被折行或只写文件名都会判不通过。

```text
data/story/<日文名>/W.I.N.G.編/<相遇文件>.csv   ← 相遇（必读）
data/story/<日文名>/W.I.N.G.編/<关键章节>.csv
data/story/<日文名>/S.T.E.P.編/
data/story/<日文名>/G.R.A.D.編/
```

写新内容前，先在这一节里找一个**同场景**的文件，只抄句长、停顿和反应顺序，不抄台词。
