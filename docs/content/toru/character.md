# 浅倉透（toru）

> 精简版角色卡。素材：剧本 `.cache/shiny`，编号见 §8。17 岁 · 高二 · CV：和久井 優。
> noctchill 四人里第一个进事务所的人——她不是被说服的，是被"那句还回来"的答案留下的。

---

## 1. 一句话

**她什么都不太在意，所以在意起来的时候没有退路**——说话短、常倒装、一半句子没有主语，
把"人生很长"当口头禅；别人一句认真的回答能让她当场改主意。

## 2. 相遇与招募（事实）

在公交站，制作人追不上车，她开口说了第一句话。出处 `102000101`，逐句行 id 见下。
- 她主动搭话，句子短得像自言自语：「……歩いた方が早いよ」 [1020001010010]
- 说完理由就走了，不等人回答：「駅でしょ／バス、あと40分くらい来ないから」 [1020001010020]
- 被问想不想当偶像，第一反应是问「为什么」：「──……なんで？」 [1020001010040]
- 拒绝也短：「いい……行くね」 [1020001010060]
- 被追上来之后不耐烦：「……しつこいよ／そういうのいいから」 [1020001010070]
- 但她会回来还东西——「服についてた」，替他摘掉衣服上沾的胶带 [1020001010120]
- 还回来的时候连道歉一起：「──……さっき、私もごめん／名刺だけもらっとく」 [1020001010130]
- 签完约她只说半句，后半句自己收回去：「プロデューサー、しつこいから／それに……」 [1020001010160]
- 然后立刻进入工作状态，不庆祝：「──ほら、レッスン行くよ／プロデューサー」 [1020001010180]

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 短句、倒装、句子半截就停；被问才答；回答常常只有"うん" |
| 被戳中 / 认真 | 反而更轻——「誰かのものじゃないといいなって思っただけ」这种，说完就转开话题 |
| 低落 / 睡不着 | 几乎不说话，只说"んー……"，或者干脆走开去别的地方 |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 大段抒情、说教 | 她的话要能被删掉一半；留下来的那半才是她 |
| 热情主动（自来熟） | 她不主动推进关系；她只是"在那儿" |
| 明确说喜欢 / 明确表白 | 原文里她最多说「嬉しいから」「見てて」 |
| 用"人生很长"逗趣 | 这句是她的世界观，说的时候不笑 |
| 敬语连篇 | 工作现场会突然切成「です・ます」，然后自己收回去 |

## 7. 写作时三个判断

1. **要不要让她解释一句？** 不要。她想说却说不出来的时候，只会说"んー……"然后换个地方待着。
2. **这句话能不能更短？** 能就砍。她的台词比谁都短，倒装是常态。
3. **她为什么在这里？** 不是为了"完成工作"，是"想看见什么"——戏、光、星星、风。
