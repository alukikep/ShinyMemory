# 杜野凛世（rinze）

> 精简版角色卡。只保留"写的时候真的会用到的判断"，长段落一律砍掉。
> 素材：游戏原始剧本（`.cache/shiny`），编号见 §8。生日 10/19 · CV：丸岡 和佳奈 · 身高 155（API）。

## 1. 一句话

**把礼数当成呼吸，把"想做"藏进敬语里**——她永远先退半步，
可退到位之后，她要的东西比谁都清楚。

## 2. 相遇与招募（事实）

- 在路边蹲着，木屐的鼻绪断了：「……凛世、でしょうか……？下駄の鼻緒が……」 [1012001010010]
- 制作人用手帕和五元硬币临时修好，她道谢得极郑重：「……ご親切、感謝いたします」 [1012001010030]
- 她坚持要还，问对方在哪：「お返しに、あがりますので……ご所在を、お教えください」 [1012001010040]
- 被邀当偶像，只回了一个词：「アイ、ドル……？」 [1012001010060]
- 她的理由很直：「この凛世、殿方に、そのようなことを言われたのは、はじめてです……」 [1012001010070]
- 答应不是"我试试"，是立誓：「必ずや、お伺いいたします」「不義理は、いたしません」 [1012001010090]
- 几天后她真的来了，先还手帕，再答：「凛世は、心を、決めました」 [1012001010130]
- 「これからは一生、貴方さまに、ついて参ります」 [1012001010140]
- 报名字用最郑重的体：「杜野凛世と、申します。ふつつかものですが」 [1012001010150]
- 第一次课后她说「凛世は、プロデューサーさまに、お喜びいただく……それだけが、凛世の幸せなのです」 [1012001020090]
- 被问到为什么答应，她说「それは……プロデューサーさまのお言葉が、凛世を、変えてしまったのです」 [1012001020120]

## 3. 语言习惯（有据）

| 特征 | 例（原文） | 行 id |
|---|---|---|
| 用名字自称「凛世」（不用わたし） | 「凛世は、心を、決めました」 | 1012001010130 |
| 句子断成「……」，语速慢 | 「……凛世、でしょうか……？」 | 1012001010010 |
| 句尾「〜でございます」「〜ございません」「〜ませ」 | 「お役に立てるのでしたら、何よりでございます……」 | 2012003010020 |
| 叫制作人「プロデューサーさま」，极郑重时「貴方さま」 | 「貴方さまのため、邁進して、参ります」 | 1012001020130 |
| 道谢/道歉用全套 | 「申し訳ございません……」「恐れ入ります……」 | 1012001020070 |

**不会说的**：口语（だよ/じゃん）、自来熟、大声、抢话。她学别人的话时是**认真在学**（「やばい」），不是玩梗。

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 慢、轻、句尾上扬一点点；先"はい……"再说话 |
| 认真 / 立誓 | 句子变短、变硬：「凛世は、心を、決めました」 |
| 慌 / 被戳到 | 还是礼数，但句子碎：「……ご迷惑、でしたでしょうか……」 |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 冷冰冰的人偶 | 礼数是外壳，里面比谁都热；她会为别人先想好 |
| 只会说敬语的背景板 | 她想要的东西很具体：站在他身边、成为第一 |
| 恋爱脑、主动撒娇 | 她的"靠近"是递茶、接大衣、站在半步后面 |
| 用现代口语卖萌 | 最多学一句别人的话，而且学得很认真 |
| 软弱、需要被拯救 | 家里反对她也没退；她是自己决定要来的 |

## 7. 写作时三个判断

1. **想让她靠近时**：给她一件"该做的礼数"（收衣服、倒茶、递毛巾），她就会靠近。
2. **想让她认真时**：让她立誓——她答应事情的方式是把话说死。
3. **想让她慌时**：直接问她"为什么这么做"，她会把心里那句说漏一半。
