# ShinyMemory

《偶像大师 闪耀色彩》同人生活模拟游戏（开发中）。

一个以“制作人”为视角、文本为主、数据驱动的养成 / 生活模拟游戏。
当前采用开放时间循环：天数持续增加，不设固定通关日。

## 当前原型

- 开放天数 × 24 小时时间系统，行动按小时推进
- 5 个地图节点：事务所、车站、练习室、录音棚、家；地点永久开放，相邻节点一步步移动，每条边独立耗时
- 选项面板下方直接显示同宽的 SVG 城市地图：当前节点、相邻节点、步行分钟数；点击相邻节点直接移动
- 车站在地图上提供公交入口：固定 ¥100 / 5 分钟直达任意地点；出租车从任意地点可用，固定 ¥400 / 3 分钟直达任意地点；钱不足时禁用
- 2 个 NPC：七草叶月（09:00–18:00）和天井努（10:00–17:00）都在事务所；各有独立 topic 和好感
- 2 个偶像：樱木真乃（练习室 08:00–14:00 / 录音棚 14:00–20:00）和风野灯织（练习室 10:00–16:00 / 录音棚 16:00–22:00）；体力/压力共享，歌唱/舞蹈/表现/信任各自使用 Rank + EXP
- 属性等级 F–S，单项满级约 500 EXP；训练/事件只给 1/3/5/10/20 档经验，升级曲线集中配置
- 训练/工作都进入偶像专属页面；练习室显示训练，录音棚显示节目收录，偶像不在场就没有入口
- 工作奖励读取目标偶像的 Rank：每个工作独立配置检查属性和权重，默认使用全局倍率表，特殊工作可覆盖倍率
- 高风险工作可以有失败率：低于 safeRank 时按差距计算失败率，失败无收入并进入点对点的失败事件；高门槛工作低于 minRank 不可选
- 高风险工作支持成功/失败事件链：`workRisk.successEventId` / `failureEventId` + `nextEventId`；模板见 `docs/work-risk-template.md`
- 10 个活动：声乐、舞蹈、表现通过偶像页面发起；节目收录/深夜综艺/大型音乐节目在录音棚；休息在事务所；睡觉在家；自由时间到处都行；每个可活动地点都可以“环顾四周”
- 行动只在时间窗内出现：训练 08:00–20:00，工作 10:00–23:59，休息/自由/环顾 08:00–22:00
- 时间/强制休息不满足 → 直接隐藏；缺钱/体力/其他条件 → 显示禁用并提示缺少项
- 睡觉：20:00 后在家睡到次日 08:00，按睡眠时长恢复体力
- 31 个事件；考核/结局内容暂时保留，但不在开放循环中自动触发
- 每个地点有一个 `look_around` 专属事件；部分事件只在特定时间段/地点出现
- NPC 交互进入专属页面，不在地点页堆 topic 按钮；叶月有 3 个 topic 和 1 个午睡事件，天井努有 3 个 topic
- 偶像交互进入专属页面；练习室显示训练，录音棚显示工作；训练/工作目标明确为当前偶像
- 侧边栏「偶像名册」打开统一属性面板，显示共享状态与所有偶像属性
- 事件选项可以消耗时间：例如深夜综艺只在录音棚 20:00–23:00 出现，接受后录制 4 小时
- 事件触发 v2：`after` / `chance` / `priority` / `cooldownActions` + `dayAtLeast` / `timeWindow`
- 事件目标：条件、效果和文本都读取 `idolId` 上下文；目标偶像的“她”会替换成名字，如“真乃”
- 自动存档（localStorage），刷新页面可继续；存档 v10 会把旧数值属性迁移到 Rank + EXP
- 调试面板：`?debug=1`，可看触发判定、强制事件、跳天
- 无 AI、无美术；先验证“选择 → 耗时 → 结算 → 事件”的开放循环

## 运行

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 生产构建
npm test         # 核心模拟测试 + 平衡烟测
```

## 结构

```
src/core/            纯 TypeScript 模拟，不依赖 React
  content/           活动、事件、结局、地点、NPC、日文本（一个内容一个文件）
  contentIndex.ts    静态内容索引（Map 查询 / after 分桶 / 地点活动 / NPC）
  config.ts          天数、分钟数、行动耗时、考核时间
  types.ts           GameState / Effect / Condition / ActorDef / LocationDef / EventDef / SaveEnvelope
  sim.ts             纯函数：时间推进、活动、移动、睡觉、NPC 对话、事件、考核、结局
  scene.ts           把 GameState 派生为 SceneView / ActionView
  time.ts            第几天 / 几点 / 时长格式化
src/save/            SaveRepository + localStorage 实现
src/ui/              React 视图，只渲染 SceneView 和状态
src/app/store.ts     Zustand 薄壳 + 自动存档
```

**节点不写死：** UI 不知道“声乐课”“深夜的练习室”这些内容，它只渲染
`SceneView` 和 `ActionView`。活动、事件、选项、结局全部来自数据。

**事件不写死：** 触发用 `after` / `chance` / `priority` / `cooldownActions`
组合，地点用 `atLocation`。地点专属事件放 `events/locations/<id>/`，
活动专属事件放 `events/activities/`，跨地点/跨活动的放各自领域文件夹。

## 状态

开放时间循环可运行：24 小时时钟、行动耗时、相邻节点移动、家/睡觉（20:00 后）、时间窗事件、存档 v10。
可用性策略：时间/强制休息不满足时隐藏，缺钱/体力/条件时显示禁用并提示缺少项。
移动：地点图由家—车站—事务所/练习室—录音棚组成；每次只能走相邻节点，各边独立耗时；地点不再关闭。
地图：选项面板下方显示与之同宽的 SVG 城市地图，规则网格布局；当前节点高亮，相邻节点可点击，显示步行分钟数。
公交/出租车：地图标题旁按可用服务显示入口；公交仅车站、¥100/5 分钟，出租车任意地点、¥400/3 分钟；弹窗选目的地，扣钱并直接到达。
NPC：七草叶月（09:00–18:00）和天井努（10:00–17:00）都在事务所，有各自 topic 和独立好感；支持多角色列表。
偶像：樱木真乃（练习室 08:00–14:00 / 录音棚 14:00–20:00）和风野灯织（练习室 10:00–16:00 / 录音棚 16:00–22:00）；体力/压力共享，歌唱/舞蹈/表现/信任使用 Rank + EXP；单项满级约 500 EXP。
名册：侧边栏「偶像名册」打开统一属性面板，显示共享状态与所有偶像 Rank/EXP，并标记当前偶像。
事件：训练/工作后事件的条件、效果和文本都读取当前偶像上下文；属性条件使用 Rank，效果使用 1/3/5/10/20 经验档位。
工作：每个工作独立配置 `baseMoney` + `checks[]`（属性/权重/可选倍率覆盖）；默认倍率表 F0.8–S1.8。
工作风险：`workRisk` 配置 minRank/safeRank/failureEventId/successEventId；结果事件使用 `entry: workOutcome` 点对点触发，链式事件使用 `entry: chain`，都不进随机池。
开放循环：天数持续增加，旧存档中的考核/结局阶段会迁回 plan；考核与结局内容保留但暂不自动触发。
旧 v1/v2 存档会保留数值，但时间线重置到第 1 天 08:00；v3–v9 存档会迁移到两名偶像 + Rank/EXP。
下一步：补车程事件，或继续训练/工作后事件。
DoL 式开放世界设计保留为后续目标，不丢弃。
