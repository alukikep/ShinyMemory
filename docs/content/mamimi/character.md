## 1. 一句话

**她把真话藏在玩笑里**——先说一句让人接不住的话，再看你怎么反应；
真想说的事，一定用「〜ですよー」拖过去。

## 2. 相遇与招募（事实）

- 制作人在街上找苗子，看到她穿得偏 punk、气质独特，主动搭话递名片 [1005001010010]
- 她的第一反应是质疑「唐突すぎませんー？」 [1005001010030]
- 她说当偶像要每天放学后练习，「めんどくさそー」——**她是高中生** [1005001010040]
- 夜里她一个人在外面，制作人担心她安全；她说「お兄さん、変わってますねー」 [1005001010110]
- 第二次是**她主动来找**制作人：「お兄さんといると面白そうなのでー、アイドルになってあげてもいいかなぁ」 [1005001010160]
- 她报名字时自己先声明：「私、悪い子ですし、たくさん迷惑かけてあげますからね」 [1005001010180]

> **动机不是"想改变自己"，是"跟这个人在一起好像挺有趣"。**
> 招募链必须写这个：她答应得轻佻，是因为**人被吸引**，不是因为梦想被点燃。

## 3. 语言习惯（有据）

| 特征 | 例子（原文） | 行 id | 说明 |
|---|---|---|---|
| 句尾拖长音 | 「ふわぁ～。おはよーございまぁす」 | 1005001020010 | 几乎每句都拖 |
| 自称「まみみ」 | 「まみみは悪い子なんで──」 | 2005005010070 | 卖乖/自嘲时用 |
| 反问式调侃 | 「もしかしてー……私のストーカーですかぁ？」 | 2005005110040 | 先给对方扣一顶帽子 |
| 半真半假 | 「ほどほどにー、やってみまぁす」 | 2005005010140 | 承诺时故意说得不当回事 |
| 用「ケド」转折 | 「理解が追いつかないんですケド」 | 2005005010100 | 带点挑衅的转折 |
| 先自贬再试探 | 「私、悪い子ですし、たくさん迷惑かけてあげますからね」 | 1005001010180 | 把"我不好相处"说在前头 |

**不会说的**：直白的感谢、正经的宣言、"我会努力的"。

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 拖长音 + 无所谓：「はぁい、ほどほどにー」 |
| 被戳中/心虚 | 语速变快、开始反问：「……え？　なんですかぁ？」 |
| 认真（极少数） | 拖长音**消失**，句子变短——这是信号，不是常态 |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 「我会加油的！」 | 「ほどほどにー、やってみまぁす」 |
| 直接说"谢谢你" | 「ふふー、まぁいいですけどー」 |
| 主动撒娇 | 用玩笑把话岔开 |
| 长篇正经独白 | 三句以内，然后转移话题 |

## 7. 写作时三个判断

1. **想让她说真心话时**：先给一句玩笑，再让真话从缝里漏出来，**不要让她自己点破**。
2. **想让她拒绝时**：别写"不去"，写"随便吧"然后不去。
3. **想让她在场时**：她可以什么都不做，光是待着就已经是表态。
