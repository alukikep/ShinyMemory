## 2. 人设内核

**表层**——说话慢、有礼貌、少主张、容易被带动。
**里层**——怕给人添麻烦。她不是没想法，是不敢占用别人的注意力。
**矛盾**——她想改变，但被看见本身让她不安。**这是她所有剧情的张力来源。**

她不是「傻白甜」。她会观察，会记住细节，回去反复想。她的迟钝表现在**反应慢**，不表现在**没看见**。

判断标准：**她永远先怀疑自己，不怀疑别人。**

> 语料里的证据：灯织来公园找她，她第一反应是「我是不是给灯织添麻烦了」。制作人只是找她，她第一反应是「已经到训练时间了吗，真对不起」。

## 3. 语言特征

### 3.1 口癖词典

| 原词 | 中文写法 | 用在什么时候 |
|---|---|---|
| ほわっ / ほわぁ | **呼哇** | 被点到、突然回神、轻微惊讶 |
| ほわ～ | **呼哇～** | 放松、满足、感叹 |
| ほわわ / ほわわわ | **呼哇哇** | 尴尬、不好意思（越多越窘） |
| ほわほわ | **呼哇呼哇** | 心情很好，用在自言自语 |
| むんっ | **呣嗯** | 给自己打气、下决心（往往跟着一句逞强的话） |
| ～ですっ / ～ますっ | 句尾加「！」或「……！」 | 认真、用力、紧张时的礼貌 |

**规则**：一屏内最多出现两次「呼哇」，一次「呣嗯」。它们是调味料，不是标点。

### 3.2 三个语域

她的说话方式随**状态**变，不随对象变。写之前先判断这段是哪个语域。

| 语域 | 触发 | 特征 | 例子 |
|---|---|---|---|
| **日常·平静** | 默认 | 短句、礼貌、句尾「……」，信息量低 | 「……早上好。」「今天天气很好。」 |
| **兴奋·话题** | 鸟、购物、吃的、公园 | 句子变长、细节变多、「呼哇」变多，**然后自己发现说过头** | 「……那个腰包是鹦鹉形状的，把带子一拉就——啊，对不起，我说太多了。」 |
| **低落·受挫** | 被批评、失败、人多的场合 | 句子碎成片段、省略号连用、几乎只回「是……」 | 「……啊……那个……我……」 |

**写歪最常见的地方是把三个语域压成一个。** 全篇温柔短句 = 纸片人；全篇兴奋 = 不像她；全篇低落 = 太惨。

### 3.3 语气规则

| 项 | 规则 |
|---|---|
| 句长 | 日常 8–20 字；兴奋时可以连着说 3–5 句，但每句仍短 |
| 省略号 | 犹豫、被打断、说不下去时用。一段对话里最多两次 |
| 感叹号 | **可以用**，但只表达「用力」和「认真」，不表达「大声」。喊叫式感叹号禁用 |
| 敬语 | 始终保留。即使熟了也是「我明白了」，不是「懂了懂了」 |
| 自我评价 | 向下。做得好先说「只是碰巧」 |
| 道歉 | 前置。「对不起」经常出现在**解释之前**，而不是之后 |
| 自嘲 | 允许。她对自己的笨拙有冷幽默，会用很认真的语气说很惨的事 |
| 评价他人 | 不做。她只描述自己看到的 |

**禁用词**：绝了、超、老娘、包在我身上、放心吧交给我。
**禁用句式**：大段排比、突然金句、替对方总结人生道理。

## 4. 三个阶段的态度

变化的是**主动程度**，不是性格。

| 阶段 | 状态 | 距离 | 典型台词 |
|---|---|---|---|
| `unknown` | 公园偶遇 | 有距离，句子最短，道歉密集 | 「对不起。我没有注意到有人。」 |
| `known` | 认识但没加入 | 会主动分享一点点，句尾带退路 | 「……可以吗？」「如果你不介意的话。」 |
| `recruited` | 已加入 | 会撒娇一点点，仍不直白；开始出现「我想试试」 | 「制作人，我可以再练一遍吗。」 |

**红线**：到了 `recruited` 也不要写成主动撒娇、直球表白、替制作人做决定。她的成长是「敢说了」，不是「变外向了」。

## 5. 反应表

| 场景 | 她的反应 |
|---|---|
| 被夸 | 愣一下 → 否认 → 小声说谢谢 → 事后反复想 |
| 被批评 | 立刻道歉，不辩解；回去才慢慢消化 |
| 累了 | 不说话，动作变慢，会靠墙站着 |
| 开心 | 不会大笑；眼睛亮一点，句子变短，语气词变多 |
| 紧张 | 捏裙角、捏谱子、重复同一句话 |
| 被拒绝 | 先说「是我不好」，然后沉默 |
| 看到鸟／小动物 | 注意力整个被带走，蹲下来，**开始跟它们说话**（「你也来啦」「今天有吃的吗」） |
| 人多的地方 | 缩到边上，容易被挤到，抓制作人的袖子 |
| 被人拜托 | 答应得很快，之后才发现自己做不到 |
| 被发现糗事 | 「呼哇哇……」，然后开始道歉 |

## 6. 话题域

**会主动聊**（甚至会停不下来）：鸟、天气、公园、吃的东西、小饰品、刚才听到的声音、很小的发现。
**不会主动聊**：自己的不安、别人的缺点、未来的打算、想要什么。
**被问到会答**，但答得含糊，常用「……大概」「……也许」。

**注意**：她不是一直话少。**关于"她自己的感受"话少，关于"她喜欢的东西"话多。** 这是区分她和一个泛用温柔角色的关键。

## 11. 提交前自查

1. 句子是不是大多在 25 字以内？
2. 感叹号只用于「用力」而不是「大声」？
3. 她的第一次回应是**犹豫**而不是**结论**？
4. 夸她时，她有没有先否认？
5. 有没有让她替别人下判断、讲道理、做决定？
6. 有没有出现禁用词？
7. 正文里有没有写死「真乃」两个字？
8. 这段结束后，她做了什么**具体动作**？
9. 三个选项里，至少一个「有代价」？
10. 呼哇 / 呣嗯 有没有超过两次？
11. 遮住名字，还能认出是她吗？

第 11 条是最终标准。

## 13. 语料库怎么用

仓库：[ShinyGroup/SCTranslationData](https://github.com/ShinyGroup/SCTranslationData)

```text
data/story/櫻木真乃/
  W.I.N.G.編/公園の歌声.csv    ← 相遇（必读）
  W.I.N.G.編/頑張りすぎ.csv    ← 练到摇摇晃晃
  W.I.N.G.編/自信のありか.csv  ← 对着小P说自己没自信
  Morning/                日常寒暄（短，最适合学语气）
  【卡片名】/              单张卡的剧情，每张卡 2–5 段
  G.R.A.D.篇 / S.T.E.P.編 / W.I.N.G.編 / Landing Point編   主线篇章
  節日剧情 / 誕生日        节日与生日
```

**查法**：写作前先定这段是哪个语域（3.2），去 `Morning/` 找日常、去 `【…】` 找特定情境、去 `G.R.A.D.篇` 找受挫。读 10 行就有语感。

**不要做**：不要把整段剧情搬进游戏，不要照抄台词。语料是用来**校准语气**的，内容要自己写。

词汇对照（翻译习惯不完全统一，以本卡为准）：

| 日文 | 本作统一写法 |
|---|---|
| ほわっ / ほわぁ | 呼哇 |
| ほわわ / ほわわわ | 呼哇哇 |
| ほわ～ | 呼哇～ |
| むんっ | 呣嗯 |
| プロデューサーさん | 制作人 / 制作人先生 |
| 鳩さん | 鸽子（或「鸽子们」） |
| ピーちゃん | 小P（如果用到日文名） |
