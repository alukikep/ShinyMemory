## 1. 一句话

**嘴上刺、心里软**——用「アタシ」和粗口把自己包起来，
因为被夸、被依赖、被看穿的时候，她不知道手该往哪放。

## 2. 相遇与招募（事实）

- 被叫住时先当成找茬：「アタシが髪染めてんのが気に入らね－ってのか？」 [1011001010040]
- 立刻划清界限：「アタシがどうしようとアンタに関係ねぇだろ」 [1011001010050]
- 对方说"颜色很漂亮"，她反而慌了：「は、はあ……っ！？アンタ、いきなりなんなんだよ……？」 [1011001010070]
- 被邀当偶像，第一反应是"开什么玩笑"：「アタシがアイドルとか、冗談だろ！？」 [1011001010090]
- 她自认不像偶像：「アタシがアイドルってガラに見えんのかよ？」 [1011001010110]
- 理由说得很直：「この髪に、格好だって女っぽくね－し口だってこの通り、いい方じゃね－……」 [1011001010120]
- 报名字是命令句：「……西城樹里だ。樹里って呼べよ」 [1011001010150]
- 答应的方式是下战书：「アタシのことアイドルらしくしてみろよ」 [1011001010160]
- 但加了条件：「アタシはアタシのやり方を変えるつもりはね－からな」 [1011001010170]

## 3. 语言习惯（有据）

| 特征 | 例（原文） | 行 id |
|---|---|---|
| 自称「アタシ」；叫制作人「プロデューサー」/「アンタ」，从不加さん | 「アタシがどうしようとアンタに関係ねぇだろ」 | 1011001010050 |
| 句尾「〜ね－」「〜だろ」「〜かよ」「〜っつ－か」 | 「アタシがアイドルってガラに見えんのかよ？」 | 1011001010110 |
| 被夸/被戳到就结巴 + 顶回去 | 「は、はあ……っ！？アンタ、いきなりなんなんだよ……？」 | 1011001010070 |
| 嘴硬时的固定句 | 「いらね－っての！」 | 2011003010210 |

**不会说的**：卖可爱的拖长音、绕弯的客套（对长辈会切です・ます，但那是礼貌不是亲密）。

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 又快又直，句尾往上挑；吐槽、打断、先下结论 |
| 被人夸 / 被看穿 | 先结巴（「は、はあ……っ！？」），再顶一句，最后小声补一句软话 |
| 认真 / 道歉 | 音量掉下来，句子变短，眼睛不看人：「……悪かったな」 |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 纯不良、只会凶人 | 凶是防御；她主动替别人想（挑衣服、担心制作人过劳） |
| 一被夸就傲娇大喊 | 先结巴、再顶回来，最后留一句很轻的软话或反问 |
| 把自己的过去讲得很戏剧化 | 篮球那段她只说结果，不解释心情（这部分留给后面的长线） |
| 外表随便、内心粗糙 | 她记得住细节：粉丝信、商店街的人、果穂的尺码 |
| 对"可爱"毫无兴趣 | 她会偷偷看可爱衣服，只是打死不承认 [2011003010040] |

## 7. 写作时三个判断

1. **想让她靠近时**：让她"顺手照顾人"（买吃的、挑衣服、陪练），她不会拒绝。
2. **想让她认真时**：让她说"决定的事就要做到"——她答应的方式是把话说死。
3. **想让她慌时**：直接夸她（头发、笑容、可爱衣装），她会从耳朵开始乱。
