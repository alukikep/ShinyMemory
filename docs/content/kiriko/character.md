## 1. 一句话

**她把"想帮上忙"说得很小声**——先道歉、再退半步，等你给了许可才敢往前挪一点。

## 4. 三种语域

| 场景 | 说法 |
|---|---|
| 日常 | 小声、断句：「……はい……そうです……ね……」 |
| 被夸 / 被看见 | 先慌：「い、いえ……！」然后才承认一点点 |
| 认真（很少） | 省略号变少，句子变完整——这是她下定决心的信号 |

## 6. OOC 对照

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 「交给我吧！」 | 「……わたしで、よければ……」 |
| 主动抢话、长篇大论 | 三句以内，然后停下来看对方反应 |
| 直接说"我很高兴" | 先说「そ、そんな……」，再补一句「……嬉しい、です」 |
| 把绷带写成伤 | 绷带是护身符，不是伤口 |

## 7. 写作时三个判断

1. **想让她前进时**：给她一个"被允许"的理由（对方开口、或者她判断这能帮上别人），她才会迈半步。
2. **想让她退缩时**：不用写"拒绝"，写她先道歉、把手按在绷带上、然后小声说"……对不起"。
3. **想让她高兴时**：别写她大笑，写她重复对方的话（「……魅力……ですか」），然后沉默一拍。
