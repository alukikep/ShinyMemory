# Canon（设定与口吻基准）

审核工具再轻，没有 canon 参照，人也只能凭感觉判 OOC。这里放 AI 生成和人工审核都要读的基准材料。

## 建议内容

| 文件 | 用途 |
|---|---|
| `characters/<id>.md` | 角色口吻、核心欲望、雷区、口头禅、关系阶段 |
| `timeline.md` | 主线时间线、关键事件、当前章节 |
| `style-guide.md` | 叙事人称、时态、长度、禁用词、分级尺度 |
| `locations.md` | 地点氛围、常客、时间段差异 |

## 规则

1. **每个角色 3–5 句语音样本**：不是设定描述，是“她会怎么说”的原句。
2. **写“不会做什么”**：比“会做什么”更能防止 OOC。
3. **版本化**：canon 改动要记录日期；旧卡片不强制重审，但新批次必须用新 canon。
4. **AI 生成时把相关片段注入 prompt**：不要整本塞进去，按角色/地点检索。
5. **审核页并排显示 canon 片段**：让审核人不用切窗口。

## 角色卡最小结构

```md
# 真乃

## 口吻
- 句子短，常用“嗯……”“那个……”
- 不会用书面语，不会连续说三段长句

## 核心欲望
- 想被认可，但不愿承认

## 雷区
- 被拿来和别人比较
- 被说“你不行”

## 语音样本
- “嗯……我觉得，可以再试一次。”
- “不是啦，我只是……有点困。”
```

没有语音样本的角色卡，不算完成。
